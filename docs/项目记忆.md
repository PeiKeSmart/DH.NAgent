## .NET 11 破坏性变更（已踩）
- apphost(.exe) 启动时 `Environment.GetCommandLineArgs()[0]` 与 `Environment.CommandLine` 返回 **exe 路径**；net10 及以前返回主程 **dll 路径**（`dotnet app.dll` 方式启动两者一致）
- 影响 `CommandHandler/Install.cs`：dll 解析增加 `Assembly.GetEntryAssembly()?.Location` 兜底 + 空值防护，否则 net11 下会把 exe 当 dll 拼进服务 FileName
